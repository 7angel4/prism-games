# Project page: Robust PAC Learning of Concurrent Stochastic Games

This branch holds only the project page for the NeurIPS 2026 paper. GitHub Pages serves it at
<https://7angel4.github.io/prism-games/>.

The code is on the [`csg-learning`](https://github.com/7angel4/prism-games/tree/csg-learning) branch.

- `index.html`, `style.css`, `page.js`: the page. Figures are inline SVG; maths in the text is rendered by
  KaTeX, loaded from jsDelivr.
- `assets/`: the RQ3 scaling plots, the poster (PDF and thumbnail) and the link-preview image.
- `.nojekyll`: tells GitHub Pages to publish the files as they are, without Jekyll.
